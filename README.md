# The Perfect Product Launch — Google Play Store Analysis
**Category:** Business, Retail & E-Commerce | **SDG 9** — Industry, Innovation & Infrastructure

## How to run
1. Download `googleplaystore.csv` from Kaggle:
   https://www.kaggle.com/datasets/lava18/google-play-store-apps
2. Put it in the same folder as these scripts.
3. Install requirements: `pip install pandas numpy matplotlib seaborn scipy`
4. Run in order:
   ```
   python week1_data_hunting.py
   python week2_know_your_data.py
   python week3_cleaning_sprint.py   # creates googleplaystore_cleaned.csv
   python week4_eda_deep_dive.py     # needs the cleaned file from week 3
   ```

## Weekly breakdown
| Week | File | What it does | Syllabus Mapping |
|---|---|---|---|
| 1 | week1_data_hunting.py | Loads data, GitHub setup notes, Pandas/NumPy basics | Unit 1 |
| 2 | week2_know_your_data.py | dtypes, info(), describe(), missing values, "First Impression" report | Unit 1 (Practical) |
| 3 | week3_cleaning_sprint.py | Cleans Installs/Price/Size/Reviews, imputes missing values, boxplot + Z-score outlier detection | Unit 2 |
| 4 | week4_eda_deep_dive.py | Univariate + bivariate analysis, distribution plots, correlation heatmap | Unit 2 (Practical) |

Each script prints its output to the console and saves any plots/reports
as PNG/TXT files in the same folder — use these directly as screenshots
in your project document and slides.
